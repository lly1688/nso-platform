# Pilot State Transition Test Matrix

This matrix is the release evidence index for the single-organization pilot.
Each referenced test runs against Testcontainers MySQL and Redis through the
shared `NsoApplicationTests` fixture.

| Business flow | Allowed transition evidence | Rejection / authorization evidence | Idempotency, concurrency, audit evidence |
| --- | --- | --- | --- |
| Project lifecycle | `ProjectChangeStateMachineIntegrationTest#v10MainLoopRunsFromReviewedRequirementToDeliveryAndArchive` covers reviewed requirement through delivery and archive. | `#v10BlocksManualProjectJumpsAndUnpreparedSampleSubmission`, `#v10DeliveryReadinessReportsBlocksAndPendingMilestonesHaveNoDate`, and `TenantIsolationIntegrationTest#ac07DeniesProjectReadForNonMember`. | `#ac08RejectsIdempotentReplayAndStaleTaskVersion`; `#ac01BlocksStaleDocumentVersionAndRecordsAudit` verifies an audit record for a rejected operation. |
| Project members and responsibilities | `#projectMembersUseDirectoryIdentityAndSupportResponsibilityLifecycle` and `#replacingProjectTechnicalOwnerReleasesTheExistingUniqueOwnerSlot`. | `AuthenticationAuthorizationIntegrationTest#fieldRoleAndAdministrativeToolsHonorTheV12PermissionBoundary`. | `AuthenticationAuthorizationIntegrationTest#profileUpdatesAreScopedOptimisticAndPasswordChangeRevokesTheCurrentSession` covers optimistic profile updates and session invalidation. |
| Sample confirmation | `PublicConfirmationIntegrationTest#sampleWorkflowCreatesAssignedTasksAndSupportsConditionalConfirmation` and `#sampleWorkflowAssignsTasksFromModernProjectResponsibilities`. | `#v10BlocksManualProjectJumpsAndUnpreparedSampleSubmission` and `FileSchedulerIntegrationTest#fileAndTaskOperationsRequireProjectScopeAssigneeAndRole`. | `PublicConfirmationIntegrationTest#customerAndPublicConfirmationEndpointsRedactInternalSampleFields` proves the external response boundary. |
| Change workflow and impact propagation | `ProjectChangeStateMachineIntegrationTest#ac03CreatesSixChangeImpactsApprovesAndBlocksAffectedTasks` and `#ac04ClosesChangeAfterAllImpactsReceiveFeedback`. | `#ac02BlocksProductionUntilSampleConfirmed` prevents downstream work before the prerequisite is met. | `#ac03CreatesSixChangeImpactsApprovesAndBlocksAffectedTasks` asserts impact propagation; `#ac01BlocksStaleDocumentVersionAndRecordsAudit` supplies audit evidence. |

Run the full matrix with `./scripts/verify-pilot.ps1`. The per-category
Surefire reports are emitted below `nso-admin/target/surefire-reports`.
