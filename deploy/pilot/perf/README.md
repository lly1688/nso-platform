# 容量验收

在隔离的试点数据副本中准备 100,000 个项目和一个具有项目读取、项目经理职责的压测账号。不要对生产数据执行此脚本。

必填环境变量为 BASE_URL 和 NSO_LOAD_TOKEN。设置 PROJECT_ID 后同时测量项目详情；默认读取项目列表和详情的 P95 目标为 2 秒。

写压默认关闭。只有设置 WRITE_PATH 和 WRITE_BODY 后才会启用 50 VU 写场景。该路径必须指向专门准备的可重复、幂等写入夹具，并提供每次请求可接受的唯一请求号；不要将真实项目状态动作作为压测目标。

复杂统计接口应在同一隔离数据集上用单独命令验证，P95 目标为 5 秒。记录 k6 JSON 结果、MySQL 慢日志、索引执行计划和幂等/乐观锁冲突响应，作为试点验收证据。
