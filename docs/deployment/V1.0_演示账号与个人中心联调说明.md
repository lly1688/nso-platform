# V1.0 演示账号与个人中心联调说明

仅在隔离的开发或验收环境启用演示数据。生产环境必须保持 `NSO_DEMO_ENABLED=false`。

```powershell
$env:NSO_DEMO_ENABLED = 'true'
$env:NSO_DEMO_DEFAULT_PASSWORD = 'demo-password-123'
mvn -pl nso-admin -am spring-boot:run
```

本地 Docker Redis 映射固定为 `127.0.0.1:6380`；`.env` 中的 `REDIS_PORT` 和应用的 `NSO_REDIS_PORT` 必须保持为 `6380`。

| 账号 | 岗位 | 默认落地页 |
| --- | --- | --- |
| `demo-admin` | 系统管理员 | 仪表盘 |
| `demo-pm` | 项目经理 | 仪表盘 |
| `demo-tech` | 技术设计 | 仪表盘 |
| `demo-process` | 工艺工程 | 仪表盘 |
| `demo-purchase` | 采购供应 | 仪表盘 |
| `demo-production` | 计划生产 | 仪表盘 |
| `demo-quality` | 质量管理 | 仪表盘 |
| `demo-customer` | 客户确认 | 个人中心 |
| `demo-executive` | 经营管理 | 仪表盘 |

登录后，右上角显示账户昵称、职责标签和岗位默认头像。选择“个人中心”可维护本人昵称、手机、邮箱、性别，上传 JPEG、PNG 或 WebP 头像（最大 2 MB），并修改密码。修改密码后，当前会话会立即失效，必须使用新密码重新登录。

验收时逐一确认：账号的菜单仅显示已授权功能；客户确认账号直接进入 `/profile` 且无重定向循环；资料版本冲突被拒绝；头像上传后立即展示；旧令牌在改密后返回未认证。
